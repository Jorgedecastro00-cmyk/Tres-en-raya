2. Breve descripción del juego?
Es una adaptación moderna y temática del clásico juego de Tres en Raya (Tic-Tac-Toe), ambientada con un estilo visual y cultural de barrio dominicano ("Patio Dominicano").Permite jugar a dos personas en el mismo dispositivo por turnos, llevando el conteo de victorias de cada equipo ("Quisqueya" contra "Los Cocoteros") y guardando automáticamente el progreso en la memoria del navegador (localStorage).

3. Qué aprendiste?
A estructurar y organizar un proyecto de desarrollo frontend utilizando React junto con Vite.A manejar estados locales (useState) y efectos secundarios (useEffect) para la persistencia de datos en el navegador.A identificar y solucionar errores comunes de sintaxis y dependencias en componentes de React, como la correcta importación de módulos y manejo de referencias.
